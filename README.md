# Create Skateboard App

The fastest way to create a new [Skateboard](https://github.com/stevederico/skateboard) app.

## Quick Start

```bash
npx create-skateboard-app my-app
cd my-app
npm start
```

## Usage

### Interactive Mode
```bash
npx create-skateboard-app my-app
```

### Skip Prompts
```bash
npx create-skateboard-app my-app --yes
```

## What You Get

- ⚛️ React v19
- 🎨 TailwindCSS v4 
- 🧩 Shadcn/ui components
- ⚡ Vite build tool
- 🔐 Authentication ready
- 💳 Stripe integration
- 🌙 Dark mode support
- 📱 Mobile responsive
- 🛣️ React Router
- 🎯 TypeScript ready

## Features Included

- Sign up/Sign in pages
- Landing page
- Dashboard with sidebar
- Settings page
- Legal pages (Privacy, Terms, EULA)
- 404 error handling
- Protected routes
- Mobile tab bar
- Customizable constants

## Requirements

- Node.js 18+
- npm or yarn
